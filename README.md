# Personal Portfolio Website

A modern personal portfolio website built with HTML, CSS, and JavaScript. It includes:

- responsive portfolio layout
- animated 3D background
- interactive terminal-style command panel
- dark/light theme toggle
- project, skill, certification, and contact sections

## Project files

- `index.html` — main portfolio page
- `styles.css` — styling and animations
- `script.js` — interactive behavior and terminal commands
- `resume.html` — resume page
- `certificates.html` — certifications page
- `profile.jpeg` — profile image

## Run locally

Open `index.html` in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Push the project files to the repository.
3. In the repository settings, enable GitHub Pages.
4. Select the branch to deploy and save.

## Notes

- Update the personal details, project links, social media URLs, and email in `index.html`.
- Replace the resume and certification files with your final versions if needed.
